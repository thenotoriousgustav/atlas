# Cabinet fonts

Latin WOFF2 subsets, self-hosted with `next/font/local` so development and production builds do not depend on Google Fonts availability.

- Geist variable, weights 100–900: https://fonts.google.com/specimen/Geist
- Geist Mono variable, weights 100–900, used for code and keys only: https://fonts.google.com/specimen/Geist+Mono
- Instrument Serif, regular and italic, used for the existing Cabinet identity: https://fonts.google.com/specimen/Instrument+Serif

Downloaded from the Google Fonts CSS API on 2026-10-20. Original SIL Open Font License files are included alongside each family.
